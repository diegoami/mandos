# Mandos-owned correction units

These units describe our own defects, without inventing an upstream dependency.
Their issues may close after normal verified main delivery.

- [Mandos198](https://github.com/diegoami/mandos/issues/198):
  [headless-shadow-fuel-198.patch](headless-shadow-fuel-198.patch) supplies the
  declared public description dependency to the headless known-world/loadout
  provider. This preserves hypothetical lamp fuel; it is not an engine patch,
  a controller policy change or a different lighting calculation. Before/after
  raw public fuel, command census, actual same-seed outcome and exhausted-lamp
  control are recorded under docs/bugs/198-headless-fuel.

Keep a unit until an equivalent owned refactor preserves its regression and
normal relevant verification. Source-port units retain their source-resolution lifecycle; C units follow
reviewed native milestones with independent TS proof/retirement. See
[the contract](../../docs/C-MILESTONE-ADOPTION.md).
